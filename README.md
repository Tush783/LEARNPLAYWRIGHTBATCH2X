# LEARNPLAYWRIGHTBATCH2X

A hands-on JavaScript learning repository — organized chapter by chapter, from absolute basics to functions, arrays, and beyond.

---

## Overview

This repository is designed for beginners and intermediate learners who want to build a solid foundation in JavaScript before moving into Playwright test automation. Each chapter focuses on one concept, with numbered scripts that progress from introduction to real-world examples and interview questions.

**What you will learn:**

- JavaScript fundamentals: variables, data types, operators, and control flow
- Scoping rules and the differences between `var`, `let`, and `const`
- Function types: basic, parameterized, returning, expression, and arrow functions
- Arrays: creation, access, mutation, transformation, searching, and sorting
- Loops: `for`, `while`, `do...while`, `for...of`, and `for...in`
- User input handling with Node.js `readline` and `prompt-sync`
- Practical interview questions (`IQ` files) woven throughout each chapter

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v16 or later (LTS recommended)
- [Visual Studio Code](https://code.visualstudio.com/)
- (Optional) Playwright for browser automation examples

### Installation

```bash
# Clone the repository
git clone <repo-url>
cd LEARNPLAYWRIGHTBATCH2X

# Install dependencies (only needed for Playwright or prompt-sync)
npm install
```

### Running a Script

```bash
node chapter_01_Basics/01_Basics.js
node chapter_12_Functions/103_Arrow_Fn.js
```

### Running Playwright Tests (if added)

```bash
npx playwright test
```

## Recommended Learning Path

Follow the chapters in order for a progressive, structured experience:

```
Chapter 01 → 02 → 03 → 04   (Environment, identifiers, var/let/const, hoisting)
Chapter 05 → 06              (Literals and operators)
Chapter 07 → 08              (Conditionals)
Chapter 09                   (User input)
Chapter 10                   (Loops)
Chapter 11                   (Arrays)
Chapter 12                   (Functions)
```

Each chapter builds on the previous one. The `IQ` (Interview Question) files inside each chapter are great for self-testing before job interviews.
