# LEARNPLAYWRIGHTBATCH2X

A hands-on repository for learning JavaScript fundamentals with organized example scripts and reference notes.

## Overview

This repository is designed for beginners and intermediate learners who want to:

- explore JavaScript language behavior through practical examples
- understand modern variable scope, functions, and control flow
- learn how VS Code shortcuts can speed up development
- review interactive and reusable JavaScript examples

## Chapters

- `chapter_01_Basics/` – JavaScript basics and Playwright setup examples
- `chapter_02_Javascript_Concepts/` – Core JavaScript topics, including identifiers, literals, and comments
- `chapter_03_Identifier_Literals/` – Reference documentation for VS Code shortcuts and identifier examples
- `chapter_04_Javascript_Concepts/` – Advanced JavaScript behavior: `var`, `let`, `const`, functions, hoisting, and block scope
- `chapter_05_Literal/` – Literal types and examples: strings, numbers, booleans, null, undefined, template literals
- `chapter_06_double_triple_equal.js/` – Equality and comparison operators, including loose vs strict checks and nullish comparisons
- `chapter_07_If_else/` – Conditional statements with `if`, `else if`, and `else` logic, including real-world examples and leap year calculations
- `chapter_08_Switch_Statement/` – Switch statements for multi-way branching, with month/day and multi-case examples
- `chapter_09_User_Input/` – Handling user input with the Node.js `readline` module and prompt examples
- `chapter_10_Loops/` – Looping constructs like `for`, `for...of`, `for...in`, `while`, and `do...while`

## What You Will Learn

- JavaScript declaration rules and identifier naming patterns
- Differences between `var`, `let`, and `const`
- Function behavior, hoisting, and scope visibility
- Control flow with conditional statements and loop constructs
- Practical examples of JavaScript execution order and engine behavior
- Useful VS Code keyboard shortcuts for Windows and macOS

## Getting Started

1. Open this repository in Visual Studio Code.
2. Review the chapter folders in order for a gradual learning path.
3. Run or inspect the example scripts to understand how each concept behaves.

## Recommended Workflow

- Start with `chapter_01_Basics` to establish a working environment and syntax familiarity.
- Move to `chapter_02_Javascript_Concepts` for foundational language behavior.
- Reference the VS Code shortcut files in `chapter_03_Identifier_Literals` while coding.
- Use `chapter_04_Javascript_Concepts` to study advanced topics like hoisting and scope.
- Practice literal types in `chapter_05_Literal` and comparison rules in `chapter_06_double_triple_equal.js`.
- Study conditional logic in `chapter_07_If_else` and `chapter_08_Switch_Statement`.
- Learn loops in `chapter_10_Loops` and handle interactive input in `chapter_09_User_Input`.

## Notes

- This repository is intended for learning and experimentation.
- Examples are written to illustrate behavior clearly rather than as production code.
- Modify and extend the example scripts to deepen your understanding.

## Requirements

- Node.js 16+ (or current LTS)
- npm or yarn
- (Optional) Playwright for browser automation examples: `npm i -D playwright`

## Quick Start

1. Clone the repository and open it in VS Code.

2. Install dependencies (if using Playwright examples):

```
npm install
npm i -D playwright
```

3. Run an example script with Node.js (example):

```
node chapter_01_Basics/01_Basics.js
```

4. To run Playwright tests (if you add tests):

```
npx playwright test
```
