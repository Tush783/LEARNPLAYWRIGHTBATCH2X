# VS Code Keyboard Shortcuts - macOS

## Window and File Management

| Action | Shortcut |
|---|---|
| New Window | `Cmd+Shift+N` |
| Close Window | `Cmd+Shift+W` |
| New File | `Cmd+N` |
| Open File | `Cmd+O` |
| Save File | `Cmd+S` |
| Save All | `Cmd+Option+S` |
| Toggle Full Screen | `Ctrl+Cmd+F` |
| Toggle Zen Mode | `Cmd+K Z` |
| Minimize Window | `Cmd+M` |
| Maximize/Restore Window | `Ctrl+Cmd+F` |

## Editing

| Action | Shortcut |
|---|---|
| Cut line | `Cmd+X` |
| Copy line | `Cmd+C` |
| Paste | `Cmd+V` |
| Undo | `Cmd+Z` |
| Redo | `Cmd+Shift+Z` |
| Move line up/down | `Option+Up` / `Option+Down` |
| Duplicate line | `Shift+Option+Down` |
| Delete line | `Cmd+Shift+K` |
| Insert line below | `Cmd+Enter` |
| Insert line above | `Cmd+Shift+Enter` |
| Format document | `Shift+Option+F` |
| Toggle comment | `Cmd+/` |
| Block comment | `Shift+Option+A` |

## Navigation

| Action | Shortcut |
|---|---|
| Go to file | `Cmd+P` |
| Go to symbol | `Cmd+Shift+O` |
| Go to definition | `F12` |
| Peek definition | `Option+F12` |
| Go to line | `Cmd+G` |
| Open command palette | `Cmd+Shift+P` |
| Show sidebar | `Cmd+B` |

## Search and Replace

| Action | Shortcut |
|---|---|
| Find | `Cmd+F` |
| Replace | `Cmd+Option+F` |
| Find in files | `Cmd+Shift+F` |
| Replace in files | `Cmd+Shift+H` |
| Find next | `Cmd+G` |
| Find previous | `Cmd+Shift+G` |

## Integrated Terminal

| Action | Shortcut |
|---|---|
| Toggle terminal | `Ctrl+` ` (backtick)` |
| New terminal | `Cmd+Shift+` ` (backtick)` |
| Focus terminal | `Ctrl+` ` (backtick)` |
| Run selected text | `Cmd+Enter` (with terminal focus) |

> Note: This list covers the most commonly used default VS Code shortcuts for editing, navigation, search, and terminal control on macOS.
