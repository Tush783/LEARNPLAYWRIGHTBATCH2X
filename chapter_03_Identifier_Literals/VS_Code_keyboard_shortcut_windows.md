# VS Code Keyboard Shortcuts - Windows

## Window and File Management

| Action | Shortcut |
|---|---|
| New Window | `Ctrl+Shift+N` |
| Close Window | `Ctrl+Shift+W` |
| New File | `Ctrl+N` |
| Open File | `Ctrl+O` |
| Save File | `Ctrl+S` |
| Save All | `Ctrl+K S` |
| Toggle Full Screen | `F11` |
| Toggle Zen Mode | `Ctrl+K Z` |
| Minimize Window | `Win+Down Arrow` |
| Maximize Window | `Win+Up Arrow` |

## Editing

| Action | Shortcut |
|---|---|
| Cut line | `Ctrl+X` |
| Copy line | `Ctrl+C` |
| Paste | `Ctrl+V` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Y` |
| Move line up/down | `Alt+Up` / `Alt+Down` |
| Duplicate line | `Shift+Alt+Down` |
| Delete line | `Ctrl+Shift+K` |
| Insert line below | `Ctrl+Enter` |
| Insert line above | `Ctrl+Shift+Enter` |
| Format document | `Shift+Alt+F` |
| Toggle comment | `Ctrl+/` |
| Block comment | `Shift+Alt+A` |

## Navigation

| Action | Shortcut |
|---|---|
| Go to file | `Ctrl+P` |
| Go to symbol | `Ctrl+Shift+O` |
| Go to definition | `F12` |
| Peek definition | `Alt+F12` |
| Go to line | `Ctrl+G` |
| Open command palette | `Ctrl+Shift+P` |
| Show sidebar | `Ctrl+B` |

## Search and Replace

| Action | Shortcut |
|---|---|
| Find | `Ctrl+F` |
| Replace | `Ctrl+H` |
| Find in files | `Ctrl+Shift+F` |
| Replace in files | `Ctrl+Shift+H` |
| Find next | `F3` |
| Find previous | `Shift+F3` |

## Integrated Terminal

| Action | Shortcut |
|---|---|
| Toggle terminal | `Ctrl+` ` (backtick)` |
| New terminal | `Ctrl+Shift+` ` (backtick)` |
| Focus terminal | `Ctrl+` ` (backtick)` |
| Run selected text | `Ctrl+Enter` (with terminal focus) |

> Note: This list covers the most commonly used default VS Code shortcuts for editing, navigation, search, and terminal control on Windows.
